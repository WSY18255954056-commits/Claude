# 手势漫画滤镜

用浏览器摄像头 + 双手，在画面里"框"出漫画滤镜窗口。多个窗口可以同时存在，每个窗口是不同的漫画画风，形成类似《蜘蛛侠：纵横宇宙》的多画风效果。

- 原生 HTML / CSS / JavaScript，无构建步骤、无后端、无登录、无上传
- 手部识别：MediaPipe Hand Landmarker（浏览器内运行）
- 实时渲染：WebGL 1 画布，所有滤镜在一个片元着色器里完成

## 运行

需要一个本地 HTTP 服务（浏览器只允许在安全上下文里访问摄像头，`file://` 不行）。

```bash
cd hand-comic-filter
npm run serve        # 等同于 python3 -m http.server 8000 --bind 127.0.0.1
```

然后用 **http://localhost:8000** 或 **http://127.0.0.1:8000** 打开，允许摄像头权限即可。

首次加载需要联网下载 MediaPipe 的 WASM 运行时（jsDelivr）和手部模型（Google Storage）。模型加载完成后，识别在本地完成，画面不会离开浏览器。

## 手势

### 普通模式（默认）

双手张开、两只手都入镜。两只手的指尖配对后，相邻指尖之间生成三个四边形滤镜区域：

| 区域 | 围成区域的指尖 | 默认滤镜 |
| --- | --- | --- |
| Thumb → Index | 左右拇指、左右食指 | 彩色漫画 |
| Index → Middle | 左右食指、左右中指 | 日漫网点 |
| Middle → Pinky | 左右中指、左右小指 | 美式波普 |

底部三个下拉框可以分别更换每个区域的滤镜。

### 新模式：拇指食指窗口

1. **进入**：双手拇指和食指靠拢（比例 < 0.8），保持约 250ms，进入新模式。
2. **窗口**：只追踪拇指和食指。左手拇指食指的中点、右手拇指食指的中点作为矩形的一对对角顶点，窗口实时跟随移动（带轻微平滑）。新模式下中指、无名指、小指不参与任何计算。
3. **复制**：双手同时捏合拇指和食指，把当前窗口复制成一个冻结窗口。冻结窗口保留复制时的位置和滤镜，不再随手移动。
   - 一次捏合只复制一次。必须先松开，才能再次复制。
   - 冻结窗口数量没有上限。
4. **换滤镜**：每次复制后，live 窗口切换到下一个滤镜，按完整列表无限循环。
5. **退出**：张开任一手（比例 > 1.05）约 300ms，或手离开画面超过约 400ms，回到普通模式。冻结窗口保留。

### 滤镜列表

| 编号 | 名称 | 效果 |
| --- | --- | --- |
| 0 | 彩色漫画 | 饱和度提升、色阶分离、黑色轮廓线 |
| 1 | 日漫网点 | 黑白，暗部用旋转网点表现，最暗处实心 |
| 2 | 美式波普 | 高饱和、4 级色阶、Ben-Day 网点、黑轮廓 |
| 3 | 黑白线稿 | 白纸上的黑色线条 |
| 4 | 黑白留红 | 高对比黑白，红色保留（Sin City 风格） |
| 5 | 赛璐璐 | 三段明暗、暗部偏冷色、细轮廓 |

滤镜列表和顺序定义在 `js/filters.js`，片元着色器的分支与之一一对应。

## Debug 线框

勾选底部的 **Debug 线框**：

- 普通模式：三个四边形区域及其滤镜名，以及参与计算的指尖点。
- 新模式：live 窗口（蓝色）、冻结窗口（紫色虚线），以及拇指食指点。

画面是镜像显示的（自拍视角），线框坐标与画面一致。

## 可调参数

所有阈值在 `js/gesture.js` 的 `DEFAULT_CONFIG` 中：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `pinchOn` | 0.30 | 双手拇指食指比例都低于它，视为捏合 |
| `pinchOff` | 0.45 | 任一手高于它，视为松开（滞回，防抖） |
| `gatherOn` | 0.80 | 双手都低于它，视为聚拢，进入新模式 |
| `gatherOff` | 1.05 | 任一手高于它，视为张开，退出新模式 |
| `enterHoldMs` | 250 | 聚拢需持续的时长 |
| `exitHoldMs` | 300 | 张开需持续的时长 |
| `lostHoldMs` | 400 | 手丢失多久后退出新模式 |
| `minWindowSize` | 0.03 | 窗口任一边的最小长度（归一化），小于它不显示、不能复制 |
| `followAlpha` | 0.6 | 窗口跟随系数，1 为无平滑 |

手掌尺度用"手腕到食指根部"的距离，因此比例与手离摄像头的远近无关。

## 设计取舍与已知限制

- **窗口的形状**：两个中点是矩形的对角顶点，窗口是屏幕轴对齐的矩形。两只手的拇指食指中点水平对齐时，窗口高度为 0，不显示也不能复制。想框出窗口，双手需要在水平和垂直方向都拉开一些距离。
- **捏合复制**：捏合是边沿触发加滞回。如果进入新模式时双手已经处于捏合状态，不会立即复制，需要先松开再捏合。
- **冻结窗口的内存**：每个冻结窗口在 GPU 上保存一张裁剪纹理。数量没有上限，但窗口很多时会占用较多显存。"清空冻结窗口"按钮可以释放。
- **识别条件**：依赖光照、手部遮挡和摄像头分辨率。光线暗或手部重叠时识别会抖动。
- **网络依赖**：首次加载需要访问 CDN。模型和 WASM 版本固定在 `js/tracker.js` 顶部，升级时一起修改。
- **未针对移动端优化**：主要面向桌面浏览器。
