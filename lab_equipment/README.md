# 实验室仪器管理系统

基于 Flask + SQLite 的轻量级实验室仪器预约与使用登记系统, 无需额外数据库, 开箱即用。

## 快速开始

```bash
cd lab_equipment
pip install -r requirements.txt
python app.py          # 浏览器打开 http://127.0.0.1:5000
```

首次启动会自动创建 `lab.db`, 并生成管理员账号 `admin` (初始密码打印在终端中, 请登录后立即修改)。
可以用 `LAB_ADMIN_PASSWORD=你的密码 python app.py` 指定初始密码。

演示数据 (5 台仪器、4 位使用人、若干预约记录) 默认也会写入; 不需要时: `LAB_NO_DEMO=1 python app.py`。

| 环境变量 | 说明 | 默认 |
| --- | --- | --- |
| `LAB_DB` | SQLite 数据库路径 | `lab_equipment/lab.db` |
| `HOST` / `PORT` | 监听地址 / 端口 | `127.0.0.1` / `5000` |
| `SECRET_KEY` | Flask 会话密钥。未设置时每次启动随机生成 (重启后需重新登录), 多进程部署须固定设置 | 随机 |
| `LAB_ADMIN_PASSWORD` | 首次启动创建管理员 `admin` 时使用的密码 (至少 8 位) | 随机生成并打印 |
| `LAB_NO_DEMO` | 设为 `1` 则不写入演示数据 | — |

## 核心功能

### 预约 (预约时间 + 使用人)
- 选择仪器、使用人, 填写**预约开始/结束时间**和用途
- 自动检测同一仪器的**时间冲突** (首尾相接不算冲突)
- 仪器可设置**单次最长预约时长**; 维护中/停用的仪器不可预约
- 不能预约已经过去的时间段; 已预约状态下可修改或取消

### 实际使用时间
- **上机签到**: 记录实际开始时间, 状态变为「使用中」; 同一仪器同时只允许一人上机
- **下机签退**: 记录实际结束时间并可填写使用情况 / 异常说明
- **补录 / 修正**: 忘记签到签退时, 可手工登记实际开始和结束时间
- 自动对比实际时长与预约时长, 标记**超时使用**
- 预约时间已过仍未签到的记录会在首页提醒, 可一键**标记爽约**

### 其他补充功能
- **仪器管理**: 名称、型号、资产编号、位置、负责人、状态 (可用/维护中/停用)、使用须知
- **维护记录**: 每台仪器的维护/校准日志及费用
- **使用人管理**: 姓名、课题组、电话、邮箱、角色; 个人使用记录与累计时长
- **日程视图**: 按天显示所有仪器的 24 小时时间轴, 点击空白处直接预约
- **统计报表**: 按仪器 / 使用人统计预约次数、预约时长、实际时长、履约率、爽约与超时次数、仪器利用率
- **CSV 导出**: 按筛选条件导出使用明细 (含预约时间、实际时间、时长), Excel 可直接打开

## 账号与权限

所有页面需要登录。账号由管理员在「账号」页面创建和管理。

| 操作 | 操作员 | 管理员 |
| --- | :---: | :---: |
| 查看仪器、预约、日程、统计、导出 CSV | ✓ | ✓ |
| 新建 / 修改 / 取消预约, 上机签到、签退, 补录使用时间, 标记爽约 | ✓ | ✓ |
| 添加 / 修改使用人 | ✓ | ✓ |
| 添加 / 修改仪器、维护记录 | | ✓ |
| 删除仪器、使用人、预约记录、维护记录 | | ✓ |
| 账号管理 (创建、改角色、重置密码、删除) | | ✓ |

- 密码以哈希形式存储; 登录失败不提示用户名是否存在。
- 不能删除当前登录的账号, 也不能把最后一名管理员降级或删除。
- 所有表单都带 CSRF 令牌校验, 跨站伪造的提交会被拒绝 (返回 400)。
- 使用人 (被预约的人) 与登录账号是两套数据, 目前不自动关联。

## 预约状态流转

```
已预约 ──签到──> 使用中 ──签退──> 已完成
  │                                 ↑
  ├──补录实际时间───────────────────┘
  ├──取消──> 已取消
  └──标记──> 爽约 ──补录──> 已完成
```
